# zoompedal

A browser tool for the Zoom G2X FOUR over USB (Web MIDI + SysEx).
Phase 1 is a read-only protocol probe.

```bash
npm install
npm run dev     # http://localhost:5173 — open in Windows Chrome/Edge
npm test
```

- How to run the probe and read the log: [docs/probe-guide.md](docs/probe-guide.md)
- Structure and decisions: [docs/architecture.md](docs/architecture.md)
